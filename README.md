# Máquina-de-averiguar-resenha
A máquina de averiguar resenha do meme.
## Funcionamento
Ela funciona usando a biblioteca <ins>Tkinter</ins> e o <ins>Python</ins>.\
Ao executar o código, uma janela aparecerá, onde pode se colocar um caminho de arquivo de texto, que será analisado a fim de achar 3 criterios, que são:\
__1.__ Presença da palavra "resenha" no arquivo especificado.\
__2.__ Quantas vezes a palavra "resenha" aparece.\
__3.__ A porcentagem do texto ocupada pela palavra "resenha".
## Instalação
Você pode optar por instalar o arquivo .exe ou pode baixar o código fonte em Python e usá-lo assim.
